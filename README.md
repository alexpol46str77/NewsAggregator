# 📰 AI-Driven Multi-Architectural News Aggregator & NLP Analytics Hub

Высокопроизводительный кроссплатформенный комплекс для асинхронного сбора новостей, лингвистического ИИ-анализа текста и интерактивной BI-визуализации. 

Проект спроектирован в рамках **концепции монорепозитория (Monorepo)** и реализует две абсолютно независимые архитектуры хранения и развертывания данных под разные бизнес-требования.

---

## 🏗️ Архитектура проекта

Проект разделен на две изолированные экосистемы:

### 1. 🪟 Windows Сборка (`/windows_sqlite_version`)
* **СУБД:** Встроенная, ультралёгкая и автономная база данных **SQLite** (`news_ai.db`).
* **Особенности:** Полная независимость от внешних серверов и виртуализации. Работа в многопоточном режиме с обходом блокировок Streamlit сессий.
* **Запуск:** Автоматизированный сценарий одной кнопкой через Windows Batch script (`run.bat`).

### 2. 🐧 Linux / Docker Сборка (`/linux_podman_version`)
* **СУБД:** Промышленная реляционная СУБД **PostgreSQL**, развернутая в изолированном контейнере Podman на выделенном защищенном томе хоста.
* **Особенности:** Полная контейнеризация ИИ-пайплайна. Python 3.12, все зависимые библиотеки и скачанные веса нейросети упакованы в единый легковесный образ (`Containerfile`) на базе `slim-Debian`.
* **Запуск:** Оркестрация и обновление данных в один клик через Bash-скрипт (`start.sh`).

---

## 🚀 Ключевой ИИ-функционал пайплайна

* **Асинхронный ETL-парсер (RSS/XML):** Одновременный параллельный сбор данных из крупнейших новостных потоков (ТАСС, РБК, РИА Новости, Интерфакс) с защитой от дублирования записей по уникальным URL-хэшам.
* **Нейросетевой ИИ-анализ (NER):** Интеграция языковой NLP-модели `spaCy` (`ru_core_news_sm`) для глубокого синтаксического разбора текстов и автоматического извлечения именованных сущностей (Персоны, Локации, Организации).
* **Умный Sentiment Analysis (Лемматизация):** Собственный алгоритм оценки эмоционального фона новостей (Позитив, Негатив, Нейтрально), работающий на базе морфологического анализа `spaCy`. Алгоритм приводит слова в любые падежи и склонения к начальной форме (лемме), обеспечивая высокую точность триггеров.
* **Интерактивный BI-Дашборд:** Аналитическая веб-панель на `Streamlit` с динамическим расчетом метрик СУБД в реальном времени, полнотекстовым поиском и сквозной фильтрацией по ИИ-сущностям, медиа-источникам и тональности.
* **Асинхронный Центр Почтовых Уведомлений:** Встроенный прямо в веб-интерфейс модуль генерации адаптивных HTML-писем и их мгновенной рассылки во входящие (Mail.ru / Gmail) через защищенные TLS/SSL протоколы.

## 🛠️ Стек технологий
* **Core:** Python 3.12, Bash, Windows Batch
* **AI & Data Science:** spaCy (NLP, Named Entity Recognition), Лемматизация, Морфология
* **Backend & ORM:** SQLAlchemy, Feedparser, Requests, Python-Dotenv
* **Databases:** PostgreSQL, SQLite
* **DevOps:** Podman, Containerfile (Dockerfile), Изолированные volumes
* **Frontend / BI:** Streamlit, Pandas, HTML5/CSS3 (для Email вёрстки)

## ⚙️ Инструкция по развертыванию (.env)

Для работы обоих модулей рассылки создайте файл `.env` в папке соответствующей сборки по следующему шаблону:
```text
MAX_BOT_TOKEN=токен_активен_но_платформа_требует_ОГРН_ИП
EMAIL_HOST=smtp.mail.ru
EMAIL_PORT=465
EMAIL_USER=your_login@mail.ru
EMAIL_PASSWORD=your_16_digit_app_secure_code
```
